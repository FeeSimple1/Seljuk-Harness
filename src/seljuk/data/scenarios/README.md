# Scenario setup data (Phase 1)

One JSON per scenario (Emperor and the Lion, Specter of Norman Betrayal, Year of
Treacherous Ambition, Showdown in Anatolia, Manzikert): Mustered Lords and
placements, Calendar markers/Service, Themata removals and face-up placements,
pre-placed map markers, Levied Capabilities, special VP rules, and Seljuk Unity
targets. Sourced from Rules of Play section 7 and the Themata and Scenario
reference.
